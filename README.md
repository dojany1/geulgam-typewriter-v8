# 글감 타자기

상단에서 **사각 글쇠**와 **원형 글쇠**를 바꿔 쓸 수 있습니다. 같은 브라우저에서는 두 화면이 글감과 초안, 작성 시간을 공유합니다.

- **사각 글쇠**는 2026년 11월 15일 오후 1시 25분(한국 시간)에 공개됐던 버전 8의 두벌식 자판입니다.
- **원형 글쇠**는 버전 14의 종이와 부채꼴 활자대를 사용합니다. 자판 아래에서 공병우 세벌식 390과 두벌식을 선택할 수 있습니다.

## 로컬에서 실행

저장소 루트에서 Python 3으로 정적 서버를 시작하세요.

```sh
python -m http.server 8000 --bind 127.0.0.1 --directory dist
```

브라우저에서 [사각 글쇠](http://127.0.0.1:8000/typewriter/) 또는 [원형 글쇠](http://127.0.0.1:8000/typewriter/round/)를 열면 됩니다. 글감 두 단어로 문장을 쓰고 Enter를 누르면 영수증을 출력합니다. Shift+Enter는 줄바꿈입니다.
