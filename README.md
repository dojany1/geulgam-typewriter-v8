# 글감 타자기

글감은 무작위로 뽑힌 두 명사를 모두 넣어 짧은 글을 쓰는 제시어 글쓰기 사이트입니다. 제시어를 쓰면 단어 옆에 ✓가 표시되고, 둘 다 쓰면 글 영수증을 뽑을 수 있습니다. ‘연필 · 치킨’이라면 ‘색연필로 치킨집 간판을 그렸다.’처럼 써도 됩니다.

상단에서 **사각 글쇠**와 **원형 글쇠**를 바꿔 쓸 수 있습니다. 같은 브라우저에서는 기본 모드와 두 타자기가 글감, 초안, 작성 시간을 공유합니다.

- **사각 글쇠**는 2026년 11월 15일 오후 1시 25분(한국 시간)에 공개됐던 버전 8의 두벌식 자판입니다.
- **원형 글쇠**는 버전 14의 종이와 부채꼴 활자대를 사용합니다. 자판 아래에서 공병우 세벌식 390과 두벌식을 선택할 수 있습니다.

## 로컬에서 실행

저장소 루트에서 Python 3으로 정적 서버를 시작하세요.

```sh
python -m http.server 8000 --bind 127.0.0.1 --directory dist
```

브라우저에서 [사각 글쇠](http://127.0.0.1:8000/typewriter/) 또는 [원형 글쇠](http://127.0.0.1:8000/typewriter/round/)를 열면 됩니다. 글감 두 단어로 문장을 쓰고 ‘글 뽑기’를 누르거나 Enter를 두 번(본문 끝의 빈 줄에서 한 번 더) 누르면 영수증을 출력합니다. Enter 한 번은 줄바꿈입니다.
