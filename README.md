## 로컬에서 실행

저장소 루트에서 Python 3으로 정적 서버를 시작하세요.

```sh
python -m http.server 8000 --bind 127.0.0.1 --directory dist
```

브라우저에서 [타자기 화면](http://127.0.0.1:8000/typewriter/)을 열면 됩니다. 글감 두 단어로 문장을 쓰고 Enter를 누르면 영수증을 출력합니다. Shift+Enter는 줄바꿈입니다.
