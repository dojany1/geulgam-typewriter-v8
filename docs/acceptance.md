# 글감 수용 기준

AGENTS.md의 규칙이 원본이고, 이 문서는 그 규칙을 세 화면(`/`, `/typewriter/`, `/typewriter/round/`)에서 확인하는 방법이다. 기능을 바꾸면 해당 표를 함께 고치고, 확인한 날짜를 표 제목에 적는다.

## 형식 예시: 한 줄 요청 → 네 답

2026-11-19에 이 형식으로 결정해 구현한 예다.

요청: “글을 뽑은 사람이 나중에 그 글을 다시 볼 수 있게 해줘.”

1. 문제와 범위 — 지금은 초안 한 건만 남아 영수증 화면을 떠나면 뽑은 글이 사라진다. 이번에는 같은 브라우저에서 목록으로 다시 보기까지 한다. 불러오기와 서버 저장은 미룬다.
2. 기능·데이터·규칙 — 글 뽑기 때 두 명사·제약·조건·본문·걸린 시간·날짜를 초안과 다른 키에 저장한다. 같은 두 명사와 같은 본문을 다시 뽑으면 한 건으로 남는다. (Given 같은 본문이 목록에 있을 때, When 다시 뽑으면, Then 목록은 한 건이고 맨 위에 있다.)
3. 흐름·화면·정보 구조 — 영수증 화면에서 저장되고, 글쓰기 화면의 도구에서 ‘뽑은 글’ 대화상자로 들어가 목록에서 연다. 열면 그 글이 초안이 되어 영수증으로 보인다. 비어 있을 때의 문구가 필요하다.
4. 완료 기준 — 글 하나를 뽑고 새로고침한 뒤 목록에서 열면 두 명사와 본문이 같다.

## 완료 버튼과 엔터 두 번 — 2026-11-23 확인

세 화면에서 실제 키 입력과 화면 자판의 Enter로, 기본 모드는 폭 375px 터치 에뮬레이션으로도 확인한다. 실제 폰 키보드 위 위치는 기기에서 본다.

| 행동 | 기대 결과 |
| --- | --- |
| 빈 종이로 연다. | 입력창 안내 두 줄 “두 단어를 넣어 자유롭게 써보세요. / 다 쓰면 엔터를 두 번 누르세요.”, 완료 버튼 ‘두 단어 남음’(흐림). |
| ‘생일 · 마당’에서 “생일 아침이었다.”를 쓰고 Enter를 두 번 누른다. | 버튼 ‘‘마당’ 남음’. 본문 끝에 빈 줄이 생기고(`\n\n`), 버튼이 흔들리며 안내 “아직 뽑을 수 없어요. 남은 글감 마당”. |
| 완료 버튼을 누른다. | 버튼이 흔들리고 안내 “아직 뽑을 수 없어요. 남은 글감 마당”. 폰에서는 입력창 초점과 키보드가 그대로다. |
| “마당에 나갔다.”를 쓴다. | 버튼이 진하게 ‘글 뽑기’, 안내 “이제 글을 뽑을 수 있어요. 다 쓰면 엔터 두 번!” |
| Enter를 두 번 누른다. | 끝의 빈 줄 없이 영수증이 나오고 뽑은 글에 보관된다. |
| ‘다시 쓰기’를 누른다. | 본문 끝에 빈 줄 문단이 되살아나고 커서가 끝에 있다. 버튼으로 뽑은 글은 그대로 돌아온다. |
| 이어 쓰고 완료 버튼을 누른다. | 영수증이 나온다. 끝의 빈 줄만 다른 같은 글은 한 건이다. |
| 본문 끝 빈 줄에서 Shift+Enter, 본문 중간에서 Enter를 누른다. | 둘 다 줄바꿈만 한다. |
| 조합 끝 신호가 오지 않는 키보드(`compositionstart`만 흉내)나 키 신호 없는 줄바꿈(`execCommand('insertLineBreak')`)으로 다 채운 글 끝에서 두 번 줄을 바꾼다. | 영수증이 나온다. |
| 폰에서 입력창을 누른다. | 완료 버튼이 화면 오른쪽 아래(키보드가 열리면 그 바로 위)에 뜨고, 안내 상자는 버튼 위에 뜬다. |
